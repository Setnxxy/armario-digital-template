# Instalar la PWA

Primero configura TU copia según [CONFIGURACION.md](CONFIGURACION.md). Abre su dirección HTTPS desde cada dispositivo y usa la misma cuenta Microsoft personal para recuperar el mismo armario.

- Chrome/Edge en computadora o Android: menú del navegador → **Instalar aplicación**, si está disponible.
- iPhone/iPad: abre tu sitio en Safari → **Compartir → Añadir a pantalla de inicio**.
- Safari en macOS compatible: **Archivo → Añadir al Dock**.

La disponibilidad y los nombres dependen del sistema y navegador. Instalar no crea otra base de datos ni otro registro Azure. La edición de OneDrive necesita internet; la interfaz puede abrir sin conexión, pero no simula guardados en la nube.

En Ajustes puedes aplicar una actualización disponible después de guardar o exportar formularios. Para desinstalar usa las opciones de tu sistema; esto no elimina archivos de OneDrive ni revoca automáticamente el consentimiento Microsoft. Al usar un dispositivo compartido, cierra sesión y revisa los datos demo/preferencias locales del navegador.
